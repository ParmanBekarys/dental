# YourDental

Тіс емханасының лендингі (React + Vite). Қазақша / орысша.

## Іске қосу

```
npm install
npm run dev
```

## Мәтінді өзгерту

- `src/data/prices.js` — емдеу бағалары
- `src/data/clinic.js` — дәрігер, телефон, мекенжай
- `src/i18n.js` — интерфейс мәтіндері

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
